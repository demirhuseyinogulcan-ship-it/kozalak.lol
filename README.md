# Kozalak AI

Official product site for Kozalak AI: a local-first botanical intelligence device with a sealed physical interface.

## Stack

- Next.js 16 App Router
- React 19
- TypeScript
- Tailwind CSS 4
- Radix UI primitives
- Framer Motion

## Local Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production Build

```bash
npm run build
npm run start
```

## Routes

- `/` English
- `/tr` Turkish
- `/ja` Japanese
- `/sitemap.xml`
- `/robots.txt`

## Domain

Production domain: `https://kozalak.lol`

The project includes canonical URLs, hreflang alternates, sitemap, robots, favicon, and Open Graph image configuration for the production domain.
